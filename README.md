# הכנה אוטומטית של הנחיות חשמל לפרויקט מגורים ועירוב שימושים – משרד טיקטין

טופס פנימי למשרד טיקטין תכנון חשמל. ראש הצוות ממלא נתונים פר מגרש, והטופס מפיק מסמך הנחיות חשמל ראשוניות לאדריכל בפורמט Word, PDF או Excel.

## מה בתיקייה

- `index.html` – הטופס עצמו (קובץ אחד)
- `gen-data.json` – נתוני הגנרטורים (שמרלינג) לבחירת גודל חדר / חופה
- `assets/` – לוגו טיקטין, נספח נוהל חח"י, תמונת גישה לרשת

## פרסום ב-GitHub Pages

1. ב-GitHub: **New repository**. נותנים שם באנגלית, למשל `residential-guidelines`.
2. בדף המאגר: **Add file → Upload files**. גוררים את **כל התוכן של התיקייה**: `index.html`, `gen-data.json`, `README.md` ואת התיקייה `assets`. בסיום לוחצים **Commit changes**.
3. **Settings → Pages**. תחת *Build and deployment* בוחרים *Deploy from a branch*, ענף `main`, תיקייה `/ (root)`, ולוחצים **Save**.
4. אחרי דקה-שתיים הטופס זמין בכתובת:
   `https://<שם-המשתמש>.github.io/residential-guidelines/`

כדי לעדכן גרסה מעלים שוב את `index.html` (Upload files) עם אותו שם.

## הבדלים מהגרסה ב-Claude

- **שמירה בענן:** לא קיימת בגרסה הזו. השמירה והפתיחה נעשות מקובץ במחשב (JSON). הטיוטה האחרונה נשמרת גם אוטומטית בדפדפן.
- **ייבוא ממצגת PDF:** עובד דרך מפתח API של Anthropic, שהוא בתשלום לפי שימוש.
  - המפתח מוזן תחת "הגדרות קריאה (מפתח API)" בכרטיס הייבוא.
  - המפתח נשמר רק בדפדפן של המשתמש.
  - בלי מפתח, כל שאר הטופס עובד רגיל.
- **הורדת קבצים:** Word / PDF / Excel יורדים ישירות לתיקיית ההורדות.

## הערות

- **גישה:** אתר ב-GitHub Pages פתוח לכל מי שיש לו את הכתובת, גם כשהמאגר פרטי (הגבלת גישה קיימת רק ב-GitHub Enterprise). אם הטופס צריך להיות סגור לאנשי המשרד בלבד, כדאי לשקול אירוח פנימי.
- **פתיחה מהמחשב:** פתיחה בלחיצה כפולה על `index.html` (file://) לא טוענת את נתוני הגנרטורים ואת השרטוטים. יש לפתוח דרך הכתובת של GitHub Pages.
- **חיבור לאינטרנט:** נדרש, כי ספריות Word / Excel / PDF נטענות מ-CDN.
